## Projects

### AI-Powered Presentation Generator
- **Problem Statement:**  
  Creating professional presentations manually can be time-consuming. The goal was to develop a platform that generates structured presentations automatically from user input.  

- **Solution Approach:**  
  - Users input text or audio describing the presentation.  
  - The system uses AI/NLP to interpret the input and ask follow-up questions about purpose, audience, and key topics.  
  - Generates slides with text and relevant images, formatted in a presentation style.  

- **Key Features:**  
  - Accepts **audio or text input**.  
  - **AI-driven follow-up questions** to refine content.  
  - Generates images using **DALL-E or free image libraries** (e.g., Unsplash).  
  - Formats content into **user-friendly presentation slides**.  
  - Provides **export options** in PPT or PDF format.  

- **Technologies / Stack:**  
  - **Front-end:** HTML, CSS, JavaScript  
  - **Back-end & AI:** Python, AI & NLP libraries, DALL-E / image APIs  
  - Cloud-based infrastructure for scalability  

- **Platform:**  
  - Web application / Cloud-hosted  

- **Expected Output:**  
  - Converts user input into structured, professional presentations.  
  - Auto-generates slides with images, text, and basic formatting.  
  - Provides customization options for design and layout.
